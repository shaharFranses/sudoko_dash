Source: autoload/sfx.gd, game/mute_state.gd, autoload/ads.gd (_request), release index.html glue, at 3f2a0b4. Release pck has autoload/sfx.gdc and game/mute_state.gdc (see B3_pck_listing.txt).
1) Ad mute: Ads._request emits ad_started after busy=true (just before the request), and ad_finished on its single exit after the result is computed (finished/error/timeout). The SDK path is bounded by an 8 s timeout loop; mock paths return. The "unavailable"/"blocked" early returns never emit ad_started, so they never mute. Sfx: ad_started -> reason "ad" on; ad_finished -> off. Master bus 0 mute = any reason active (MuteState). No path stays muted. PASS. GUT: test_ad_mutes_during_and_restores_after, test_ad_error_and_timeout_unmute, test_ad_end_keeps_hidden_mute, test_unavailable_ad_does_not_touch_mute.
2) Hidden/blur: there is NO visibilitychange listener and NO blur/focus handling. Sfx._process polls document.hidden every 0.25 s and sets/clears reason "hidden"; NOTIFICATION_APPLICATION_PAUSED/RESUMED only apply on mobile/desktop. FAIL vs spec:
   - blur (window focus lost while still visible, e.g. clicking outside the portal iframe) is never handled, so audio keeps playing.
   - Hidden relies on Godot's main loop running. Browsers throttle or stop requestAnimationFrame in hidden tabs, so the poll may not run promptly (up to 0.25 s + throttling) and the mute may land late or not at all. Restore on visible works (the next poll after rAF resumes).
   Fix: in the head glue, add document 'visibilitychange' + window 'blur'/'focus' listeners that set a flag Godot reads (or suspend/resume window.__sdAudioCtxs directly, which works even while the main loop is paused), or handle NOTIFICATION_APPLICATION_FOCUS_OUT/IN in sfx.gd.
3) Gesture resume: the head glue wraps window.AudioContext/webkitAudioContext before index.js loads, records instances in window.__sdAudioCtxs, and calls resume() on non-running contexts on pointerdown/touchend/keydown/mousedown (capture phase, not removed after the first gesture; harmless). PASS (static). A runtime check needs the browser.
